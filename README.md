# Field Notes — Portfolio học tập INF2501

Portfolio cá nhân cho học phần **Nhập môn Công nghệ số và ứng dụng trí tuệ nhân tạo**. Website sử dụng HTML, CSS và JavaScript thuần; không cần quy trình build.

## Cấu trúc

- `index.html` — About Me
- `projects.html` — tổng quan 6 bài tập
- `projects/bai-tap-1.html` đến `projects/bai-tap-6.html` — trang chi tiết từng bài
- `conclusion.html` — tổng kết học phần
- `assets/css/` và `assets/js/` — tài nguyên dùng chung
- `assets/images/`, `assets/documents/`, `assets/videos/` — nơi bổ sung tư liệu cá nhân

## Chạy cục bộ

Mở thư mục này bằng VS Code và chạy `index.html` với Live Server. Các trang dùng đường dẫn tương đối để hỗ trợ GitHub Pages.

## Bổ sung nội dung

Thay các phần trong ngoặc vuông bằng thông tin và sản phẩm thực tế của bạn. Không dùng placeholder làm minh chứng sản phẩm. Khi thêm ảnh, hãy cập nhật `alt` mô tả ảnh; khi nhúng tài liệu hoặc video, đặt tệp trong thư mục tương ứng và dùng đường dẫn tương đối.
